Conectar ao GitHub

Sem Supabase e sem códigos por e-mail. Use uma autorização do GitHub com acesso apenas ao repositório grace-com-artes.

No GitHub, crie um token de acesso refinado (Fine-grained token), selecione apenas o repositório grace-com-artes e habilite Contents: Read and write. Defina uma validade e não compartilhe o token. Ele ficará somente nesta aba do navegador.

Criar autorização no GitHub

O token não é enviado para este site: ele é usado diretamente pelo navegador na API oficial do GitHub. Ao fechar a aba, você precisará informá-lo novamente.
